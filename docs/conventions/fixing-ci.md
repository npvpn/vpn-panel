# Конвенция: фикс упавшего CI (GitHub Actions)

По ссылке на упавший прогон/джобу/PR доводим CI до зелёного локально: вытащить логи, воспроизвести, починить по сути. Команда не коммитит и не пушит.

Кратко:

- Вытащить логи упавших шагов: `gh run view ID --log-failed` или `gh pr checks N`.
- Воспроизвести **той же командой**, что в CI: `uv run mypy app`, `uv run ruff check`, `uv run pytest`.
- mypy «new errors» чинить в коде, не `sync` — baseline только уменьшается.
- Граница: зелёные локальные проверки → отдаём пользователю, коммит делает он (`/commit`).

`telegram_bot/docs/conventions/fixing-ci.md`.
