# Конвенция: написание тестов

Новая логика в `app/` приходит вместе с тестами, а не «потом». Цель — постепенно поднимать покрытие.

Кратко:

- Новый модуль/функция с бизнес-логикой → обязательно тесты.
- `tests/` зеркалит структуру `app/`: логика из `app/foo.py` → `tests/test_foo.py`.
- Баг → сначала тест, воспроизводящий баг (red), потом фикс (green).
- Асинхронные тесты: без декоратора (в конфиге `asyncio_mode = "auto"`).

Полные правила — в репозитории бота:
`telegram_bot/docs/conventions/writing-tests.md`.
