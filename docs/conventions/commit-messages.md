# Конвенция: именование коммитов

Заголовок коммита следует формату `NPVPN-XXXX: суть на русском`. Так как PR сливается через Squash and merge, по этой конвенции оформляются заголовок и описание PR — они становятся итоговым коммитом.

Кратко:

- Префикс: `NPVPN-XXXX:` (код задачи в Yougile). Только для работ без задачи
  допускается тип вместо кода: `chore:`, `fix:`, `refactor:`.
- Суть на русском, по-деловому, без точки. До ~72 символов.
- Описание (тело) — на русском, объясняет «почему» и что важно ревьюеру.
- GitHub при Squash and merge сам допишет номер PR `(#N)` — вручную не пишем.

Полные правила — в репозитории бота:
`telegram_bot/docs/conventions/commit-messages.md`.
