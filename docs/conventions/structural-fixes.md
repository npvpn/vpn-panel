# Конвенция: структурная правка вместо правки по месту

Когда баг вызван тем, что обязанность размазана по коду, чини конструкцию, а не отдельное место. Правильный приём, после которого ошибку повторить становится невозможно или заметно на ревью.

Кратко:

- Обязанность в N ветках выхода → один выход, одна точка правки.
- Не тиражируй плохой паттерн соседнего кода «по аналогии» — внедряй правильный сразу.
- Инвариант в комментарии → инвариант в конструкторе или вычисляется явно.
- Структурная правка → с тестами, покрывающими все ветки.
