# Конвенция: статусы задач в Yougile

Ведём статус задачи в чате Yougile, пока идёт работа. MCP не редактирует сообщения, поэтому используем новые сообщения, а не правку старых.

Кратко:

- Первое сообщение: `[SUMMARY]` со статусом, что сделано, ссылка на PR.
- Доработки: новое короткое сообщение-апдейт в тот же чат, только дельта (не дублируем `[SUMMARY]`).
- Язык: рабочие термины из кода нормальны; не углубляемся в реализацию.
- Ссылка на PR — в `[SUMMARY]`, как только он создан.

Полные правила — в репозитории бота:
`telegram_bot/docs/conventions/yougile-updates.md`.
