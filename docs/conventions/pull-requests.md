# Конвенция: оформление Pull Request

Заголовок PR — это будущий squash-коммит; описание становится телом коммита. PR открываем на `master`.

Кратко:

- Ветка: `NPVPN-XXXX/<kebab-slug>`. Перед открытием ребейз на свежий `master`.
- Заголовок и описание — по [конвенции коммитов](commit-messages.md).
- Ревьювер назначается по умолчанию; база — `master`, голова — твоя ветка.
- На каждый не-черновой PR приходит CodeRabbit как советчик, не как блокер мержа.

Полные правила — в репозитории бота:
`telegram_bot/docs/conventions/pull-requests.md`.
