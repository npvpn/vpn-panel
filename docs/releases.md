# Релизные теги панели

Панель релизится вместе с ботом и использует общую схему версий — **CalVer**:

```
vYYYY.MM.DD          плановый релиз            v2026.07.29
vYYYY.MM.DD.N        хотфикс в тот же день     v2026.07.29.1
```

В релизный день бот и панель тегаются **одной датой**, даже если изменений в панели
мало. Тег docker-образа — это тег git без префикса `v`: `v2026.07.29` даёт
`npvpn/panel:2026.07.29` (и `ghcr.io/npvpn/panel:2026.07.29`).

`__version__` в `app/__init__.py` с тегами не синхронизируется и остаётся как есть.

Полные правила, чек-лист выпуска и порядок хотфикса — в репозитории бота:
`telegram_bot/docs/conventions/releases.md`.
